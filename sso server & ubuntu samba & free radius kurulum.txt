## 2. Statik IP ve DNS Tanımlaması (Netplan)

Netplan yapılandırma dosyasını tam yol ile aç:

ls -l /etc/netplan/


```bash
nano /etc/netplan/00-installer-config.yaml

```

Dosya içeriğini aşağıdaki gibi düzenle (*DNS çözümlemesinin kopmaması için `nameservers` bloğu eklenmiştir*):

```yaml
network:
  version: 2
  renderer: networkd
  ethernets:
    ens3:
      dhcp4: no
      addresses:
        - 192.168.23.141/24
      routes:
        - to: default
          via: 192.168.23.2
      nameservers:
        addresses:
          - 8.8.8.8
          - 1.1.1.1

```

Yapılandırmayı doğrula ve üret:

```bash
cat /etc/netplan/00-installer-config.yaml
netplan get
netplan generate

```

`systemd-networkd` dosyasında `DHCP=ipv4` olmadığını kontrol et:

```bash
cat /run/systemd/network/10-netplan-ens3.network

```

Yapılandırmayı uygula:

```bash
netplan apply

```

Hosts dosyasını güncelle:

```bash

192.168.23.141 dc1.test.com dc1

::1             localhost ip6-localhost ip6-loopback
```

## 4. Port 53 Hazırlığı & DNS / Paket Yöneticisi Kurtarma

Samba dahili DNS servisini (`Internal DNS`) kullanacağı için port 53'ü dinleyen 
`systemd-resolved` stub resolver'ı devre dışı bırakılmalıdır.

### Adım 4.1: Port 53'ü Boşaltma ve systemd-resolved'u Kapatma

ss -lntup | grep ':53'

```bash
systemctl disable --now systemd-resolved

```

`systemd-resolved` kapatıldığında sembolik link kopabileceğinden, `/etc/resolv.conf` dosyasını statik olarak tanımla:

```bash
rm -f /etc/resolv.conf
cat > /etc/resolv.conf << 'EOF'
nameserver 8.8.8.8
nameserver 1.1.1.1
EOF

```

Portun serbest kaldığını ve internete erişimin sürdüğünü doğrula:

```bash
ss -lntup | grep ':53'
ping -c 3 archive.ubuntu.com

```

*(Port 53 çıktısında `systemd-resolved` görünmemeli, ping başarılı dönmelidir.)*

### Adım 4.2: Olası Paket Kilidi (Lock) ve Süreç Temizliği

Eğer arka planda takılan `unattended-upgrades` veya `apt` süreçleri varsa temizle:

```bash
systemctl stop packagekit 2>/dev/null
killall -9 apt apt-get unattended-upgrade 2>/dev/null

rm -f /var/lib/apt/lists/lock
rm -f /var/cache/apt/archives/lock
rm -f /var/lib/dpkg/lock*

dpkg --configure -a

```

21.2 FreeRADIUS ntlm_auth modülünü TEST domainine göre ayarlama

ÖNEMLİ:
FreeRADIUS, /etc/freeradius/3.0/mods-enabled/ klasöründeki dosyaları
configuration olarak okur.

Bu nedenle ntlm_auth dosyasının yedeğini mods-enabled klasörünün
içine .bak uzantısıyla koymuyoruz.

Yedeği /root altında oluştur:

cp /etc/freeradius/3.0/mods-enabled/ntlm_auth \
   /root/ntlm_auth.bak


Dosyayı aç:

nano /etc/freeradius/3.0/mods-enabled/ntlm_auth


Mevcut örnek satır buna benzer:

program = "/path/to/ntlm_auth --request-nt-key --domain=MYDOMAIN --username=%{mschap:User-Name} --password=%{User-Password}"


Dosyanın içeriğini şu şekilde yap:

exec ntlm_auth {
    wait = yes
    program = "/usr/bin/ntlm_auth --request-nt-key --domain=TEST --username=%{mschap:User-Name} --password=%{User-Password}"
}


Kaydet ve çık.


Ardından henüz FreeRADIUS servisini restart etmeden configuration kontrolü yap:

freeradius -XC


Beklediğimiz:

Configuration appears to be OK


NOT:
Eğer daha önce yanlışlıkla şu şekilde bir yedek oluşturulduysa:

/etc/freeradius/3.0/mods-enabled/ntlm_auth.bak

FreeRADIUS hem ntlm_auth hem de ntlm_auth.bak dosyasını okuyacağı için:

Duplicate module "exec ntlm_auth"

hatası oluşur.

Bu durumda yedek dosyayı mods-enabled klasörünün dışına taşı:

mv /etc/freeradius/3.0/mods-enabled/ntlm_auth.bak \
   /root/ntlm_auth.bak

Sonra tekrar kontrol et:

freeradius -XC

Beklediğimiz:

Configuration appears to be OK


21.3 – FreeRADIUS authentication akışını ntlm_auth'a yönlendireceğiz.

Amacımız radtest ile gelen PAP parolasını ntlm_auth üzerinden Samba AD'ye doğrulatmak.

Önce default dosyasının yedeğini alalım. Yedeği yine sites-enabled içine koymuyoruz:

Dosyayı aç:

Dosyanın içinde:

authorize {

bölümünü bul.

Bu bölümün en başına, { satırından hemen sonra şunu ekle:

    if (&User-Password) {
        update control {
            Auth-Type := ntlm_auth
        }
    }

Yani başlangıcı kabaca şöyle olacak:

authorize {

    if (&User-Password) {
        update control {
            Auth-Type := ntlm_auth
        }
    }

    filter_username
    ...

Sonra aynı dosyada:

authenticate {

bölümünü bul.

Bu bölümün içine şunu ekle:

    Auth-Type ntlm_auth {
        ntlm_auth
    }

Örneğin:

authenticate {

    Auth-Type ntlm_auth {
        ntlm_auth
    }

    Auth-Type PAP {
        pap
    }

    ...
}

Kaydet ve çık.

### 5. SSO Menü Scripti ve İzinleri

```bash

cat > /opt/sso/sso_menu.py << 'EOF'
#!/usr/bin/env python3
import os
import sys

device_user = os.environ.get("USER")
if not device_user:
    print("Cannot detect USER, exiting.")
    sys.exit(1)

while True:
    sys.stdout.write("search or select one:")
    sys.stdout.flush()
    line = sys.stdin.readline()
    if not line:
        continue
    ip = line.strip()
    if not ip:
        continue
    if ip.lower() in ("exit", "quit"):
        sys.exit(0)
    break

cmd = ["ssh", "-o", "StrictHostKeyChecking=no", f"{device_user}@{ip}"]
os.execvp(cmd[0], cmd)
EOF

chmod 755 /opt/sso/sso_menu.py
python3 -m py_compile /opt/sso/sso_menu.py

```

### 6. SSH Daemon Yapılandırması (Port 2222 + ForceCommand)

`/etc/ssh/sshd_config` dosyasının yedeğini alın:

```bash
cp /etc/ssh/sshd_config /root/sshd_config.bak

```

Dosyada portu `2222` yapıp `kcusers` grubu için ForceCommand kuralını dosyanın en sonuna ekleyin:

```bash
# Varsa eski Port satırını güncelle, yoksa başa ekle
if grep -q "^#*Port " /etc/ssh/sshd_config; then
    sed -i 's/^#*Port .*/Port 2222/' /etc/ssh/sshd_config
else
    sed -i '1i Port 2222' /etc/ssh/sshd_config
fi

# Dosya sonuna Match bloğunu ekle
cat >> /etc/ssh/sshd_config << 'EOF'

Match Group kcusers
    ForceCommand /opt/sso/sso_menu.py
    PermitTTY yes
    AllowTcpForwarding no
    X11Forwarding no
EOF

```

Yapılandırma kontrolü ve servisi yeniden başlatma:

```bash
sshd -t
systemctl daemon-reload
systemctl restart ssh.socket ssh.service 2>/dev/null || systemctl restart ssh

# Port dinleme kontrolü
```

### 7. Uçtan Uca Doğrulama (Windows / İstemci Tarafı)

#### Manuel SSH Testi

Windows terminalinden:

```bash
ssh -p 2222 student1@192.168.23.145

```

* Parola: `Passw0rd1`
* Ekrana `search or select one:` prompt'u geldiğinde `192.168.23.181` yazıp enterlayın.


* Cihaz şifresi sorulduğunda tekrar `Passw0rd1` girerek SW1 CLI promptuna ulaşıldığını görün.



#### Otomasyon Testi (Python Netmiko)

```python
import os
import platform
from netmiko import ConnectHandler, redispatch

server_ip = '192.168.23.145'
ip = '192.168.23.181'
device_username = 'student1'
decrypted_password = 'Passw0rd1'

def ping_device(target_ip):
    param = '-n' if platform.system().lower() == 'windows' else '-c'
    null = 'nul' if platform.system().lower() == 'windows' else '/dev/null'
    return os.system(f"ping {param} 1 {target_ip} > {null} 2>&1") == 0

if not ping_device(ip):
    print(f'ip:{ip}, ping:False, sso_ssh:False, device_ssh:False')
else:
    print(f'ip:{ip}, ping:True')
    print('Connecting to SSO server...')
    try:
        server = {
            'device_type': 'terminal_server',
            'host': server_ip,
            'username': device_username,
            'password': decrypted_password,
            'port': 2222,
            'conn_timeout': 30,
            'global_delay_factor': 2,
            'session_log': 'outputx.log'
        }
        jump_conn = ConnectHandler(**server)
        print('SSO Sunucusuna baglanildi.')

        jump_conn.read_until_pattern(pattern='search or select one:', read_timeout=30)
        print(f'>> IP gonderiliyor: {ip}')
        jump_conn.write_channel(f"{ip}\n")

        jump_conn.read_until_pattern(pattern=r"[Pp]assword:", read_timeout=30)
        print('>> Cihaz sifresi gonderiliyor...')
        jump_conn.write_channel(f"{decrypted_password}\n")

        prompt_out = jump_conn.read_until_pattern(pattern=r"[>#]", read_timeout=30)
        print(f'>> Prompt alindi: {prompt_out.strip()}')

        redispatch(jump_conn, device_type='cisco_ios')
        
        output = jump_conn.send_command('show ip interface brief')
        print("\n--- Cihaz Ciktisi ---")
        print(output)
        
    except Exception as e:
        print(f'Hata: {e}')
    finally:
        if 'jump_conn' in locals():
            jump_conn.disconnect()

```
