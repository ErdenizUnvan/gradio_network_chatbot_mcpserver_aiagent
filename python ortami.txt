eger soyle bir hata gelirse:
Error running MCP Inspector: Cannot find native binding. 
npm has a bug related to optional dependencies (https://github.com/npm/cli/issues/4828).
Please try `npm i` again after removing both package-lock.json and node_modules directory.

Python/FastMCP değil, Node/npm + MCP Inspector dependency problemi.
Özellikle Node v24.21.0 çok yeni; burada en temiz yol önce npm'in npx cache'ini tamamen temizlemek.

CMD'de sırayla:

rmdir /s /q "%LOCALAPPDATA%\npm-cache"

Sonra:
npm cache verify

npx @modelcontextprotocol/inspector
